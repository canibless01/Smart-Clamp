# B8. Outage Incident Detail
Route `/ops/incidents/[id]`. Audience: scoped ops/utility aggregate variant. Foundation addition to close an implicit product flow; not an extra approved hardware product.

## Content in reading order
Affected topology version; source observations and confidence bounds; supply/communications timeline; missing devices; notifications and dispatch; restored coverage.

## Buttons and behavior
Assign field job; inspect authorized device; update incident; mark reviewed resolution.

No community-wide switching button. Utility sees region-filtered projection; timestamp uncertain shown as interval; false alarm closes episode with audit and corrective notification if needed.
