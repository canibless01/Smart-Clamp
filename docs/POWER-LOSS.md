# Supercapacitor and outage timestamp contract
Source master03.6–03.7 explicitly requires a small supercapacitor, no maintenance battery. This supplements L03/L04. It stores enough electrical energy for a bounded final save; it does not promise device operation throughout an outage or a guaranteed cellular transmission.

## Required physical design
Detect loss on the upstream regulated supply before the held-up MCU rail collapses. Use an isolated power-good/comparator circuit into the proposed power-fail inputGPIO39 (input-only, externally biased). Capacitor must have controlled charging/inrush, appropriate voltage rating, reverse-current isolation so it does not back-power the load/modem/mains supply, and a regulator path that keeps MCU+storage above minimum operating voltage. Prefer shedding modem/radio/LED loads immediately; GSM transmission peaks cannot be assumed covered by a tiny capacitor. All values require a qualified schematic and measured worst-case current/ESR/temperature/aging behavior.

Sizing uses energy, not an arbitrary “1F”: usable energy = 0.5*C*(Vhigh²−Vlow²)*efficiency; required C >=2*Psave*tsave/[efficiency*(Vhigh²−Vlow²)], plus measured margin for ESR, regulator dropout, charge state and component tolerance. Determine Vlow from regulator+ESP32+flash reliable-write requirements. Source's “few seconds” is a design target to measure at temperature/end-of-life, not a certified existing property.

## Firmware lifecycle
1. Before any failure: journal telemetry incrementally, preserve most recent trusted UTC anchor+uptime, installation/calibration/key epoch, energy counters and command intent/receipt. Reserve bounded space for power-fail marker and avoid full journal rewrite.
2. Interrupt: capture monotonic timer and set a power-fail flag. No allocation, network, printf, NVS/filesystem or blocking work in ISR.
3. High-priority save task: disable new switching/network/OTA operations; capture compact fixed record{boot_id,seq,uptime_at_loss,last_utc_anchor,anchor_uptime,clock_quality,voltage,energy counters,relay_feedback,config_epoch,CRC}. Persist to pre-erased reserved slot with sequence+commit marker; old valid slot retained until new commit complete. Never erase a flash sector at last gasp. If flash writes cannot meet brownout envelope, qualify dedicated FRAM/EEPROM adapter and appropriate power budget.
4. Send last-gasp notification only if adequate remaining measured energy and reachable connection; never delay save awaiting upload. Do not start cellular attach as a prerequisite for logging.
5. Fully unpowered: no additional measurements, no ticking RTC promise without power, no claim that commands can be received or relays changed. Latching relay retains physical state as designed; supply absence does not prove relay opened.
6. Boot: read both journal slots, select latest committed CRC-valid record. If neither valid, report outage_time_unknown; never synthesize precision. Obtain new trusted time; infer supply return from qualified voltage samples, keeping timestamp confidence. Upload original loss record with measured vs received timestamps and backfill flag. Cloud dedupes episode by original identity. PowerFail marker and voltage-debounced source event correlate, not duplicate SMS.

Clock: timestamp = last trusted UTC anchor + monotonic elapsed before failure, with anchor age/uncertainty. After full power loss uptime restarts; do not extend old monotonic timer across reboot. NITZ is hint; signed/TLS authenticated server time supplies trust. Unknown-time record retains uptime and boot identity; can establish bounds, not exact tariff allocation.

## Fault acceptance tests
Instrument supply rails and power-good; test worst-case save while radios active, low charge, degraded capacitor, journal near full, repeated mains flicker, failure mid-record, failure mid-command pulse and OTA, cold/hot component limits. Cut power at every write boundary and verify old/new complete record survives, never corrupt partial selected. Repeat restores with no SIM/no internet and compare stored outage time to independent clock. Log actual hold-up milliseconds, write duration/current, UTC error and CRC recovery. Host runtime tests cannot qualify this circuit. Bench build still has no implemented physical power-fail storage adapter.
