# Device/cloud protocol v1 (foundation decision)
Transport-independent contract. These messages replace Blynk virtual pins. Firmware report and command APIs are **not** arbitrary client Supabase writes. Source path /devices/{id}/readings is legacy; new integrations use /device/events, /device/poll, /device/receipts under /api/v1.

## Identity and wire bytes
Manufacture assigns random UUID device_id and a unique 256-bit secret for each direction (telemetry and commands), key_epoch >=1. Gateway has its own keys and per-peer encrypted link keys; it cannot forge a child reading. Provision via authenticated BLE/secure manufacturing. Never reuse sample/test keys or store them in Git. Encryption at rest and physical provisioning security are required separately.

Envelope JSON has exactly device_id, key_epoch, payload_b64, signature. payload_b64 is unpadded URL-safe base64 of exact UTF-8 payload bytes. Signature lowercase hex HMAC-SHA256 over UTF-8 `SC1\n{device_id}\n{key_epoch}\n{payload_b64}` using the appropriate direction key. Compare constant-time before parsing inner JSON. Outer device/epoch must match inner target/identity. Canonical inner JSON: sorted keys lexicographically, compact separators, ASCII-escaped strings, integer-only numeric values, booleans/null permitted; floats/NaN/duplicate keys forbidden. Thus MCU libraries may serialize canonical bytes or receive them pre-serialized; do not reconstruct a command before verifying it. Max envelope16KiB, max signed payload8KiB. Supply key bytes decoded from encrypted credential storage, not hex text unless explicitly decoded. Reference implementation and golden vectors are in reference_protocol.py / vectors.json.

## Telemetry payload
Required: kind=`telemetry`, device_id, key_epoch, boot_id(random128-bit lowercase hex), seq(monotonic within boot), occurred_at_ms(UTC or null if untrusted), uptime_ms, clock_quality(trusted/estimated/unknown), config_epoch, role, quality(valid/gap/uncalibrated/sensor_fault), metrics. metrics include voltage_mv, current_ma, real_power_mw, import_mwh, export_mwh; integer units are explicit (mWh is milli-watt-hour, not megawatt-hour). Hub has metrics={} and kind=heartbeat; never emits invented metering. Events kind=supply_lost/supply_returned/protection/tamper/config/heartbeat use same identity and sequence with event-specific detail. Store received_at separately; never overwrite measured timestamp with receive time and label it accurate.

Unique(device_id,key_epoch,boot_id,seq). Same ID same payload hash returns prior ACK; same ID different hash returns409 security conflict. Unknown or stale credential epoch returns401. ACK body includes device_id,key_epoch,boot_id,seq,payload_sha256,committed=true. TLS-authenticated cloud durable commit ACK is relayed verbatim over authenticated local link; it is not a gateway packet ACK. Queue deletes only exact committed identity+hash. Replay of old telemetry returns deduped ACK and no repeated billing. Clock-unknown events may be stored but cannot bill/correlate exact tariff interval until reconciled.

## Command payload
Required: kind=`relay_command`, device_id, key_epoch, config_epoch, command_id(UUID), seq(persistent global counter for this key epoch), issued_at_s, expires_at_s (<=issued+120), on(boolean), policy_epoch, reason, authorization_ref. Sign whole payload using command-direction key. Only boolean on/off on this wire message; schedule/budget policies are separate versioned signed objects with restricted semantics. No raw TOTP that can be copied onto a different action.

Device verifies signature, target/key/config epochs, trusted clock, expiry, monotonic sequence and commissioning. Persist command receipt with sequence and pending action before pulse. On duplicate command_id return stored result; never pulse again. If reset occurs after persisted intent but before pulse/ACK, query auxiliary feedback and resolve uncertain outcome without replaying a toggle. Command is absolute state, not toggle. Feedback unknown rejects ON; unsafe condition rejects ON. Local protection may open without network and is reported later. User/utility authority is server-side, not trusted from unverified free-text reason. Use signed policy_epoch to invalidate queued commands after revoke/config change; maximum120s expiry bounds residual in-flight exposure. Urgent revocation cannot guarantee delivery to an offline device; UI must say pending/last known, not instant physical revocation.

Receipt is signed as device event: kind=command_receipt, command_id, command_seq, result(applied/rejected/uncertain), observed_on(boolean/null), reason_code, observed_at_ms, plus normal identity fields. Backend binds to issued command and treats applied only with compatible observed feedback. Requesting ON may be refused by independent local OFF reasons.

## Poll and TLS
Device poll is signed kind=poll with nonce/seq and current receipt cursor; server response carries list of signed command envelopes, durable telemetry ACKs and signed time/config version. Default poll30s, adaptive backoff5s–15min with jitter on network errors. Keep network calls outside sensor task. API TLS certificate chain must validate; no insecure TLS fallback. Clock bootstrapping uses configured trust anchors and stored last trusted lower bound; NITZ alone is not sufficient authorization time. Rotate fleet trust roots in a signed config update before expiry. Device request max16KiB; gateway forwards bounded batches preserving individual envelopes.

## ESP-NOW
Assigned one-hop pole peers on a provisioned channel; no multi-hop feeder mesh. Encrypted unicast with peer identity and per-link credentials. Payload frame version1, message UUID, part index/count, total_length, fragment CRC32; max frame200bytes including header to stay below legacy250-byte limit. Reassembly max16KiB, max4 simultaneous messages, timeout10s; missing indexes requested, retry capped5 before backoff. CRC detects damage, HMAC verifies origin. Local frame ACK does not imply cloud commit. Fair per-peer queues, bounded memory, persist originals and retransmit after reboot. OTA uses separate signed manifest/chunk channel; verify full image signature/hash before boot, never execute code from a fragment.

## RS485
Hub is sole master, room nodes addresses1–247 bound to device ID in commissioning map; half-duplex 9600baud 8N1 reference, configurable after field test. Frame: magic0x5343, version1, address,u8 message_type,u32 request_sequence,u16 payload_length (network byte order),payload,CRC32(header+payload). Max payload512bytes; fragments carry envelope message UUID/index/count. Only addressed slave responds; turnaround20ms; response deadline500ms; 3 retries then mark link stale. No unsolicited slave transmissions or broadcasts that actuate relays. Electrical bus requires isolated3.3V transceiver, correct bias/termination and qualified cabling; UART settings alone cannot fix physical noise. HMAC end-device envelope survives hub forwarding.

## IR, modem and handheld adapters
Optical DLMS/COSEM requires approved meter model, optical interface timing, baud negotiation, OBIS mappings and association security. Modbus requires register map and scaling. Treat unsupported adapter as unsupported_meter, never fake balance. LoRa needs additional selected radio module/channel plan/range test; GSM fallback is a separate transport profile. SIM7000 and SIM800 are not interchangeable AT/TLS implementations. Reference design selects SIM7000-class LTE-capable modem pending Nigeria carrier/band qualification; legacy2G SIM800 is not automatic fallback. Handheld downloads original signed journal and uploads through same deduping API; collector cannot mint a reading. OTA and key rotation require authenticated signed metadata, not a public write endpoint.
